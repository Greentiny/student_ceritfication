# 🎓 QR코드 특인 프로그램

학생 인증을 위한 학번 입력 시스템입니다.

## ✨ 주요 기능

### 📥 입력 화면
- **학번 입력창**: 5자리 학번 직접 입력
- **간단한 안내**: "입력해주세요" 메시지

### 📤 출력 화면
- **학생 정보 표시**: 이름, 학번, 학년, 반
- **학년별 뱃지 시스템**:
  - 🟦 3학년: "Lv.3 Senior" (파랑)
  - 🟧 2학년: "Lv.2 Intermediate" (주황)
  - ⚪ 1학년: "Lv.1 Beginner" (흰색)
- **애니메이션 효과**: 부드러운 화면 전환 및 호버 효과

### ⚠️ 에러 화면
- **사용자 친화적 오류 메시지**
- **시각적 피드백**: 흔들림 애니메이션
- **쉬운 복구**: 뒤로 가기 버튼

## 🎨 디자인 특징

### 게임 UI 스타일
- **그라데이션 배경**: 현대적인 디자인
- **글래스모피즘 효과**: 반투명 카드 디자인
- **부드러운 애니메이션**: 모든 상호작용에 애니메이션 적용
- **반응형 디자인**: 모바일 및 데스크톱 최적화

### 학년별 색상 시스템
- **3학년**: 파랑 계열 (#4A90E2)
- **2학년**: 주황 계열 (#FF9500)
- **1학년**: 흰색 계열 (#F8F9FA)

## 🚀 사용법

### 1. 프로그램 실행
```bash
# index.html 파일을 웹 브라우저에서 열기
open index.html
```

### 2. 학번 형식
**학번 형식**: 학년(1자리) + 반(1자리) + 번호(3자리)

예시:
- `31001` - 3학년 1반 1번
- `23001` - 2학년 3반 1번
- `12001` - 1학년 2반 1번

## 🔧 커스터마이징

### 색상 변경
`styles.css` 파일에서 학년별 색상을 수정할 수 있습니다:

```css

    background: linear-gradient(45deg, #새로운색상1, #새로운색상2);
}
```
